§1Installation

TERMy is a single static binary. No runtime, no package manager, no ceremony — drop it on the PATH and it is installed.

$ curl -sL termy.sh | sh
$ termy --version
termy 3.1.0 (build 2026-07-31)
Heads-up: on first run TERMy creates web_templates/ in the current directory. That folder is yours — edit themes, add schemes, delete what you don't use.

§2Core commands

Three verbs cover ninety percent of daily work.

CommandWhat it does
termy generate webCompile a themed site from web_templates/ into its own project directory.
termy contextInspect or rewrite the persisted session key-value store.
termy saySpeak a line through the voice engine — used for build confirmations.

§3Flags & environment

VariableEffect
TERMY_TEMPLATESPoint at an alternate web_templates/ root.
NO_COLORDisable ANSI color in all logging output.
TERMY_QUIETSuppress the voice engine entirely.

§4Rules of the road

Templates are data, not code — a missing css or js file is never an error, only a warning. Every build is reproducible from the same inputs, and nothing outside the project directory is ever touched.
